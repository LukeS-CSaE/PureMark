# PMD 使用手册

---

## 1. 产品简介

**PMD** 是一款\*\*极简、本地优先（local-first）\*\*的 Markdown 编辑器。

- **本地优先**：所有文件就是普通的 `.md` / `.markdown` 文件，直接写在你的磁盘上，**没有账号、没有云同步、没有数据上报（telemetry）、没有导出/订阅**。你写的东西永远属于你。
- **目标平台**：Windows 桌面 `.exe`（通过 Tauri 2 封装，Rust 内核 + WebView 渲染）。
- **设计哲学**：打开即写、所见即所得、不折腾。系统级亚克力毛玻璃外观，排版干净。

---

## 2. 快速开始

### 2.1 启动方式

- **直接运行**：拿到 `PureMark.exe` 双击即可，无需安装、无后台服务。

- **从源码构建（开发者）**：

  ```bash
  pnpm install          # 安装依赖（本机真机执行，非沙箱）
  pnpm tauri dev        # 开发模式热重载
  pnpm tauri build      # 打包出 Windows 安装包 / 便携 exe
  ```

  > 类型检查：`npx tsc -p tsconfig.app.json --noEmit`（务必用这条，根 tsconfig 是空引用、普通 `tsc --noEmit` 会"假通过"）。

### 2.2 首次使用

1. 打开应用后，默认界面是一个带毛玻璃效果的编辑器主窗。
2. 点击侧栏的"打开文件夹"或"打开文件"，选择一个含 `.md` 的目录即可开始。
3. 默认视图是 **Live（实时排版）**，直接开始打字就能看到排版后的效果。

## 4. 核心功能详解

### 4.1 文件管理

- **打开文件夹 / 单文件**：侧栏按钮打开，仅显示 `.md` / `.markdown` 文件（含 md 的目录也会保留）。
- **多标签页**：可同时打开多个文档，新建 / 打开 / 关闭 / 切换；有改动时标签显示 `*`。
- **文件树**：侧栏展示目录结构，点击即在焦点窗格打开。
- **文件关联**：已注册 `.md` 扩展名，**双击系统中的 .md 文件会直接用 PureMark 打开**（若已在运行，会聚焦已有窗口并打开该文件）。
- **保存**：
  - `Ctrl+S` 立即把内容**写回原文件**。
  - 未手动保存时，应用会**自动保存草稿**（存本地 store，不会污染原文件），防止意外丢失。
  - 关闭带未保存内容的标签 / 窗口时，会弹出确认拦截。

### 4.2 三种视图模式

每个窗格可独立切换（工具栏或视图切换），三种视图的样式保持高度一致：

| 视图 | 说明 |
| --- | --- |
| **edit** | 纯源码编辑，带 Markdown 语法高亮。 |
| **live** | **实时排版**（Typora 风格）：非活动行隐藏语法标记、显示排版结果；回车定格上一行；点击活动行可还原源码继续编辑。输入法（IME）受保护不会闪跳。 |
| **preview** | 只读渲染预览，适合最终检查。 |

### 4.3 分屏（工作区布局）

- 工作区支持 **single（单窗格）/ split（双窗格 A/B）**。
- 双窗格可：
  - **同一文件**左右对照（共享同一份内容，但各自独立滚动位置）；
  - **不同文件**对照编辑。
- 每个窗格的视图模式相互独立（例如左边 live、右边 preview）。
- 可关闭其中一个窗格回到 single。
- 跨窗格滚动同步：当 split 且左右是"同一文件 + 一边 edit/preview、另一边相反"时，滚动会联动；其它组合各自独立。

> 已知限制：分隔条当前**不可拖拽**调整比例（比例已可持久化，但 UI 暂无拖动手柄）。

### 4.4 主题与主题色

- **明暗模式**：`light` / `dark` / `auto`（auto 跟随系统 `matchMedia` 自动切换）。整界面走 CSS 变量 token 化。
- **主题色（强调色）**：7 种预设 —— `sky`（默认）/ `blue` / `green` / `purple` / `orange` / `red` / `pink`。即时生效并记忆，亮暗模式共用。

### 4.5 目录（TOC）

- 自动从正文解析标题生成目录，**会跳过围栏代码块内的** `#`。
- 工具栏"目录"开关控制显示；支持**左 / 右**位置切换（右侧为独立面板，约 220px，`clamp()` 自适应）。
- 点击目录项可跳转：live/edit 滚动到对应行，preview 滚动到对应标题（预览标题已自动打锚点 id）。

### 4.6 搜索（Ctrl+F）

- 拦截浏览器原生查找，改用**应用内搜索面板**：
  - 在 Markdown 纯文本上计算匹配；
  - 结果高亮、可逐条导航；
  - 跳转时三视图（edit/live/preview）各自正确处理滚动定位（live/preview 是富文本渲染，已做偏移校正，不会跳错位置）。

### 4.7 状态栏统计

实时显示：行号 / 列号、总行数、词数、字数、编码（UTF-8）与文件类型（Markdown）。

### 4.8 窗口几何记忆

- 关闭时记住窗口大小与位置，**下次启动精确还原**；100% / 125% / 150% 缩放下不再漂移。
- 通过系统 `window-state` 作为唯一真相源。

### 4.9 全局禁用右键菜单

- 为保持界面纯净，**全应用禁用了 WebView 原生右键菜单**（含输入框）。
- 但 `Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+A` 等快捷键**完全不受影响**，复制粘贴照常。

## 7. 技术架构与组件选型（开发向）

### 7.1 技术栈总览

| 层 | 选型 | 版本 / 说明 |
| --- | --- | --- |
| 桌面壳 | **Tauri 2**（Rust + WebView2） | Windows `.exe`；插件 `dialog` / `fs` / `store` / `single-instance` |
| 前端框架 | **React 18** + **TypeScript 5.5** | 函数组件 + Hooks |
| 构建 | **Vite 5** + `@vitejs/plugin-react` | 开发热更新 / 打包 |
| 样式 | **Tailwind CSS v4**（`@tailwindcss/vite`） | `@theme inline` 映射设计 token |
| 状态管理 | **zustand v4** | 4 个 store：tabs / UI / config / panes |
| 测试 | **vitest 2** | `environment:"node"`，无 jsdom（UI/视觉需真机测） |
| 图标 | **lucide-react** | 0.439 |

### 7.2 编辑器内核（双栈）

| 视图 | 引擎 | 关键依赖 |
| --- | --- | --- |
| **edit** | **CodeMirror 6** | `@codemirror/state` `@codemirror/view` `@codemirror/commands` `@codemirror/language` `@codemirror/lang-markdown` `@lezer/markdown` `@lezer/highlight` `@lezer/common` |
| **live** | **TipTap / ProseMirror**（Typora 风格零可见语法） | `@tiptap/core` `@tiptap/react` `@tiptap/pm` `@tiptap/starter-kit` + 扩展 `image`/`link`/`placeholder`/`table-*`/`task-*` + `tiptap-markdown@0.8.10`（v2 线） |

> 说明：早期（v1/iter2）live 由 CodeMirror 6 的"装饰覆盖"实现，因零可见语法与稳定性不可兼得，于 2026-08-11 起**全量迁移到 TipTap/ProseMirror**。Markdown 落盘采用"源码保留型序列化器"，保证字节级一致（未改动的块原样回写，仅改动块重新生成）。edit 视图仍用 CM6，CM6 完全移除为后续计划（P3）。

### 7.3 Markdown 渲染与高亮

- **预览区渲染**：`marked`@14
- **代码高亮**：`highlight.js`@11（按需注册语言 + 自写基于 CSS 变量的配色）
- **live 装饰**：基于 CM6 markdown 语法树（仅 edit 视图用）

### 7.4 目录 / 搜索 / 主题 等纯逻辑

- 均放在 `src/lib/` 纯 TS 层（可 node 单测）：`toc`、`search`、`theme`（强调色派生）、`windowGeometry`、`scrollSync`、`headingAnchors` 等。

### 7.5 架构模型

- **三层概念**：文档层 `EditorTab`（单 buffer 全局唯一内容）→ 窗格层 `Pane.viewMode`（edit/live/preview，每窗格独立）→ 工作区层 `WorkspaceLayout`（single/split）。
- **两套正交注册表**：`editorRegistry`（编辑器句柄，edit/live 注册）、`tocRegistry`（目录跳转目标）。
- **路由收敛**：打开/聚焦/分屏/关闭只走 `lib/paneRouter.ts`；TOC 开关联动只走 `lib/tocRouter.ts`。
- **Rust 壳**（`src-tauri`）：`build_tree`（读目录）、`take_launch_file`（取启动文件）、`single-instance`（二次启动转发 `open-file`）、文件关联（`std::env::args()`，非 macOS 的 `RunEvent::Opened`）、窗口 `decorations:false + transparent:true + windowEffects:["acrylic"]`。
